## 三、关键口径（成员3及以后成员必读）

1. **延误标签**：主目标 `arr_del15`（到达延误≥15分钟）；`cancelled`、`diverted`、到达时间缺失分别标记，一律**不填为准点**。
2. **天气匹配规则**：每班匹配计划起飞UTC时刻**之前**最近一条 FM-15/FM-16 观测，间隔≤90分钟（字段 `gap_minutes`）；另含60分钟窗口敏感性字段 `within_60`。同时刻多条观测按 FM-15 优先。**一行一班**，不因天气连接产生重复行。
3. **缺测≠无雨**：降水字段无值（`precip_reported=0`）不等于无降水记录，降水9.03%缺失已如实报告。
4. **三条例外**：XWA（无匹配站点，1,972班不关联天气）、SGU（位置冲突，不在正式346站清单，3,023班）、WYS（72676494163仅2024-04-29~11-06覆盖，覆盖外时段不补造天气）。
5. **未匹配说明**：`no_obs_within_90` 的18,904班并非天气全空，而是附带间隔>90分钟的陈旧观测（中位194分钟）；真正天气全空仅 XWA+SGU 共4,995班。建模前建议按 `matched` / `within_60` 过滤。
6. **时区**：`sched_dep_utc` 由当地 `sched_dep_local`（FlightDate+CRSDepTime）按起飞机场IANA时区转换，已处理夏令时、2400（全年1条）、11月回退夜。

## 四、使用环境与打开方式

- Python 3.11+；读 Parquet 需 `pip install pyarrow`（或 pandas 2.0+ 自带依赖）。
- 解压后保持目录结构，所有路径相对项目根 `flight_delay_project/`。
- 快速查看：直接打开 `flights_weather_2024_sample.csv`；全量分析用 Parquet 按列读取。

## 五、校验方法

解压后逐文件计算 SHA-256，与本包 `metadata/member2_deliverable_checksums.sha256` 比对，应全部一致：

```powershell
certutil -hashfile "data\integrated\flights_weather_2024.parquet" SHA256
```

未核验项（如全量质量码逐条人工复核、陈旧观测合理性）已在 `docs/quality_report.md` 第10节如实声明，不作为已核验结论。
