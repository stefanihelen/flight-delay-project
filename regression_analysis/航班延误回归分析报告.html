航班延误回归分析报告

2024年BTS航班与NOAA天气融合数据｜课程中期项目回归部分｜分析日期2026年11月7日

本分析检验天气与到达延误的调整后关联，并比较加入天气信息是否改善未来月份的预测。对全年融合主表的7,079,060班航班进行完整读取与核验，主Logit最终使用6,272,067班有效到达航班。强风、低能见度和有降水与更高的延误优势相关；这些结果不构成因果证据。

与无降水相比，1小时有降水的调整后优势比为1.937（1.767–2.124）；能见度不足1公里相对至少10公里为2.822（2.128–3.742）。测试期ROC-AUC从0.612变为0.645。这些数字的含义、概率校准和样本选择限制须结合下文解读。

研究问题与作业要求的对应关系

核心问题是：在控制计划起飞时间、航司、机场和航程后，出发机场附近的天气与到达延误是否仍有关联；天气能否提供超出这些航班特征的预测信息。BTS提供航班结果与计划信息，NOAA提供实际天气观测，二者通过机场与气象站匹配以及时间对齐共同进入模型。只有航班数据无法识别天气关联，只有天气数据无法定义航班延误。

分析样本和延误目标

主目标为到达延误至少15分钟：未取消、未备降，且到达延误分钟有限、原始到达延误标签为0或1的航班进入有效到达分母；由分钟阈值重新定义目标并核对标签。提前到达保留为未延误。取消、备降或结果未知不能简单填成未延误。

敏感性目标为取消、备降或到达延误至少15分钟的复合受扰结果。它保留天气与控制条件合格的取消、备降航班，因此回答的是另一种运行受扰问题，不能与条件于有效到达的延误率混为同一分母。预处理另保留了60分钟严重延误标签，但本次没有拟合对应模型。

风速与能见度分组沿用描述统计，保留非线性且便于说明参照。类别代码只是标签：使用哑变量并省略参照组，或者由fixest吸收固定效应；不会把机场代码、月份或天气类别编码作为连续数值。温度采用预先指定的15°C中心和10°C尺度及平方项，不从测试集估计标准化参数。

气压、露点和风向不进入本次主模型：气压与露点并非回答本次问题的必要首选变量，加入会扩展完整记录筛选并增加解释复杂度；露点与温度还可能高度相关。风向是圆周量，不能把0–360度直接作为线性大小，同时缺少跑道方向，不宜将风向系数解释为侧风关联。这些是本次预设的简约变量选择，不意味着它们没有预测信息。实际起飞延误、实际到达时刻、延误原因及到达延误分钟不得作为预测特征；其中到达分钟仅用于构造目标，以避免结果泄漏。

天气质量与时点核验

天气必须匹配成功，并在计划起飞前0–90分钟内。核验使用dep_utc−weather_obs_utc与记录的weather_gap_minutes对照；缩窄至60分钟作为敏感性检验。这里使用的是临近计划起飞时可获得的天气观测，不能称为提前一天预报。

主样本要求四种天气数值有限，风速、能见度和降水非负，降水累计期恰为1小时。质量码接受集合为0, 1, 4, 5, A, C，另比较四要素均为1或5的保守子集。其他码属于预设集合之外，不能自动解释为错误或缺失；NOAA码9表示要素存在时通过粗略范围检查。本主表中四要素数值存在且质量码为9的计数分别为{'temp_q': 0, 'wind_speed_q': 0, 'vis_q': 0, 'precip_q': 0}。没有把缺失降水改为零降水，也没有将不同累计时长混在一起。

有限的极端值未因大小而自动缩尾或删除。分组能见度降低了极端高值对线性斜率的影响，但不能证明异常来源已被纠正。已核验的是交付字段内部的一致性；机场与站点空间映射、源数据真实性及原时区转换没有在本次逐条重建。

模型设定与不确定性

logit P(延误≥15分钟 = 1 | 有效到达, X)
 = 风速类别 + 能见度类别 + 有降水
 + (温度−15)/10 + [(温度−15)/10]² + ln(航程英里/500)
 + 出发机场FE + 到达机场FE + 航司FE + 月份FE + 星期FE + 计划起飞小时FE

使用R fixest::feglm的二项Logit和吸收固定效应。主模型经过5轮迭代收敛。协方差按出发机场与日期双向聚类，容许同机场跨日期以及同日期跨机场的相关性；这不是把“机场×日期”组合当一个聚类。主模型区间使用t分布，自由度min(333, 366)−1=332。同一天气观测可能服务多班航班，不能将所有航班视作独立气象观测。

对数优势系数取指数得到OR。OR大于1表示条件延误优势较高；它不是风险比，也不是延误概率增加相同百分比。温度升高10°C的关联取决于起点，通过一次项与平方项的线性组合和完整协方差计算区间。9项天气对比是预设的描述性比较；95%区间均为逐项区间，不保证9项同时以95%覆盖。P值没有做多重比较校正，在数百万样本下很小的P值也不能替代效应量、实际意义及识别条件。这是探索性调整关联，不是因果检验。

时间外推的拟合与评估

1–8月训练，9–10月验证并选择阈值，11–12月作为独立测试期。模型比较包括仅控制变量与控制变量加天气，均在相同训练和测试口径下进行。没有随机打散全年，没有类别平衡或过采样。分类阈值在验证集0.05–0.60、步长0.01的网格上最大化F1；并列时取较低阈值，测试集不再调阈值。

为避免训练没有11–12月类别却无法估计其月份固定效应，预测模型采用预先指定的两组年度Fourier谐波sin(2πd/366)、cos(2πd/366)、sin(4πd/366)、cos(4πd/366)，保留机场、航司、星期和小时固定效应。全年关联模型仍使用月份固定效应；两类模型服务不同目的，不能把全年拟合质量冒充时间外推成绩。类别为训练期无法估计的水平时预测可能缺失，以下报告覆盖并只在两个模型共同可预测记录上比较。

概率校准与结果的实际含义

控制模型平均预测23.30%，高于实际延误率17.39%，差值+5.92个百分点；控制＋天气模型平均预测20.97%，高于实际延误率17.39%，差值+3.58个百分点。排序能力改善不等于概率已准确。校准图按各模型测试概率的分位数最多分10组，展示平均预测和实际发生比例；这些是描述点，没有区间，也没有在测试集上再校准。总体均值相近也不能保证所有概率段都可靠。

例如天气模型最高预测概率组的平均预测为43.63%，实际延误比例为33.89%，说明高风险端的概率仍有偏差。是否需要再校准应在额外开发数据上决定，并用新的独立测试期验证，不能用本测试集拟合后又在同一批航班报告改进。
